# E-Commerce Application

A full-stack E-Commerce web application built using MERN Stack.

## Tech Stack

Frontend:

* React.js
* JavaScript (ES6)
* HTML5
* CSS3
* React Router
* REST API Integration

Backend:

* Node.js
* Express.js
* MongoDB
* Mongoose

## Features

* User authentication
* Product listing
* Add to cart
* CRUD operations
* API integration
* Responsive UI
* Admin dashboard
* Product management

## Project Structure

frontend/

* React application

backend/

* Express API server

admin/

* Admin panel

## Installation

Clone the repository

```
git clone your-repository-link
```

Install dependencies:

Frontend:

```
cd frontend
npm install
npm start
```

Backend:

```
cd backend
npm install
node index.js
```

Admin:

```
cd admin
npm install
npm run dev
```
